# Home Chat

Simple chat application designed for home use.

## Features

- Real-time messaging
- WebSocket support
- REST API for settings and messages
- SQLite database for message storage

## Project Structure

```
client/         # Frontend code
server/         # Backend code
configs/        # Configuration files
db/             # Database files folder
cert/           # Dev SSL certificates
```

## Running the Application

### Using Docker Compose

```bash
# Run
npm start

# Run via Docker
docker-compose up --build
```
